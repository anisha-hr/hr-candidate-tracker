 # HR Candidate Tracker

## Project Overview

This is a beginner HR recruitment project created to track candidates throughout the hiring process.

## Recruitment Workflow

1. Job Requirement
2. Candidate Sourcing
3. Resume Screening
4. Shortlisting
5. Interview Scheduling
6. Interview
7. Selection
8. Offer
9. Joining

## Candidate Information Tracked

- Candidate Name
- Position
- Experience
- Location
- Recruitment Status
- Interview Date
- Follow-up Status

## Example

| Candidate | Position | Experience | Status |
|---|---|---|---|
| Rahul | BPO Executive | 1 Year | Shortlisted |
| Priya | Customer Support | 6 Months | Interview |
| Arun | BPO Executive | 2 Years | Selected |

## Skills Demonstrated

- Recruitment workflow understanding
- Candidate tracking
- Interview coordination
- Basic data management
- GitHub basics
